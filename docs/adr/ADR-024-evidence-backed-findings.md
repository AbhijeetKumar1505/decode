# ADR-024: Treat Evidence and Findings as First-Class State

**Status:** Accepted

## Decision

Evidence is immutable provenance. Findings use candidate, confirmed, rejected,
not-reproducible, mitigated, and regression states. Confirmation requires
declared validation and independent review where required.

## Consequences

Reports derive from state. Leads remain explicit. Integrity, access, retention,
and safe export are required.
